# Remaining production blockers

The repository is safer and more testable, but production readiness is intentionally blocked by facts that cannot be inferred from source code.

1. Verified operator identity and any public business details.
2. Address and governing-law decisions, if legally appropriate.
3. Reviewed audience treatment and related privacy/consent obligations.
4. Qualified approval of policy, use, and trademark wording.
5. A valid AdSense account, publisher/slot plan, consent plan, and an account-supplied `ads.txt` line if advertising is later enabled.
6. An owner-approved deployment and live revision/crawl verification.
7. Per-record editorial review before any candidate audience/detail metadata is published.

None of these blockers is bypassed by this commit.
