## 6. Generator changes

`pipeline/lib/printable-title-quality.mjs` remains the deterministic correction owner. The change adds confirmed replacements, phrase cleanup, terminal public-suffix removal, an explicit uncommon-word allowlist, and a non-dictionary quality classifier. `pipeline/scripts/build-printable-title-quality.mjs` records classifier warnings as editorial review flags while still treating real safety defects as generation blockers.

Generation remains local, deterministic, dependency-free, and API-free. Duplicate numbering still uses frozen canonical path and stable ID ordering; all 69 duplicate groups remain two-record `Design 1` / `Design 2` groups.

## 7. Title-quality rules

The quality classifier now identifies:

- Confirmed misspellings.
- Adjacent repeated words.
- Known repeated phrase order.
- Redundant `Coloring Page` endings.
- Empty and extremely short titles.
- Titles over the current 80-character review guidance.
- Unexplained numeric suffixes.
- Generic placeholders.
- Internal filenames, IDs, hash fragments, storage, local, or pipeline leakage.
- Uncertain terms that need editorial review.

Approved uncommon terms such as `Pteranodon`, `Pterodactyl`, `Mosasaurus`, `Plesiosaurus`, `Iguanodon`, and `Ankylosaurus` have explicit false-positive coverage. No broad dictionary was introduced.

## 8. Hub review methodology

Every public hub was inventoried with title, introduction, governed supporting fields, count, membership, indexability, and sitemap status. The new deterministic analysis measures exact duplication, token-overlap near duplication, repeated sentence openings, vague phrases, unsupported claims, internal leakage, repeated hub subjects, and whether introduction wording has support in the actual member-title inventory.

Shared functional wording such as `coloring pages`, `printable pages`, and `US Letter` is removed before similarity scoring. Simple singular/plural and `mythic`/`mythology` normalization prevents obvious false positives.

## 12. Metadata changes

The previous public description helper exposed generic orientation/collection prose. It now provides one truthful, route-specific workflow description:

`Print {display title}, or download a printable-page PNG or JPG and an artwork-only WebP.`

This matches current behavior, retains the subject at the start, distinguishes printable-page images from artwork-only WebP, avoids unsupported claims, and stays below 210 characters for every record. All 6,352 descriptions remain unique because the generated display titles are unique.

Metadata titles remain unique and bounded at 128 characters. Titles over the 70-character guidance decreased from 2,400 to 2,398; no subject was truncated merely to chase an arbitrary length. Canonicals, robots, pagination metadata, Open Graph structure, and schema types were not changed.
