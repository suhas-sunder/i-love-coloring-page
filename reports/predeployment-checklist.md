# Pre-deployment checklist

- [x] Production ad default remains OFF; no live publisher or slot configuration was added.
- [x] No broad content rewrite, bulk metadata promotion, redirect, or noindex expansion was applied.
- [x] Count/indexation/asset/SSR foundations from the prior audit remain in place.
- [x] Metadata candidates have an explicit local-only per-record review workflow.
- [x] Obsolete failing source snapshots are archived outside active test discovery.
- [ ] Owner/legal/account gates in `reports/owner-input-required.md` are resolved.
- [ ] A production build is approved and deployed by the owner.
- [ ] Homepage and representative inner routes return the same `build-revision.json` revision.
- [ ] Production browser checks pass at the listed desktop/mobile viewports.
- [ ] Production crawl, canonical, robots, image-sitemap, and asset-origin checks are rerun.
- [ ] Any future live-ad proposal receives publisher, slot, consent, age-treatment, and placement review.
