# Final UX Fix Current Audit

| Area | Finding |
| --- | --- |
| Header/nav hover | Present but too quiet; needs clearer hover treatment while preserving focus-visible. |
| Card print action | Redundant visible card-level Print button exists below each card. |
| Image click | Image surface already opens the modal, but it needs a subtle overlay cue. |
| Image spacing | Component/CSS can leave the preview feeling padded instead of image-first. |
| Modal | Print and Close are top-right, but the modal still has avoidable scrollbar risk and an unnecessary Download label beside buttons. |
| Downloads | PNG, JPG, and WebP are available; SVG is not exposed. |
| PDF output | One-page PDF workflow exists, but current PDF draws three frame lines and has too much padding. |
| Branding | Branding is outside the artwork area, but the frame/padding needs tightening. |
| Link sections | Related and browse links are purposeful in data, but spacing/count alignment still looks cramped. |
| More menu | Grouping is preserved, but desktop width, count alignment, and wrapping need polish. |

No deployment, live QA, GSC, upload, ad code, backend, taxonomy, or media-path work was performed for this audit.
