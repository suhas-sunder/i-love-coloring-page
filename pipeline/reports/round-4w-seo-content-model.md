# Round 4W SEO Content Model

## Homepage
- Metadata: Unique brand and library metadata.
- Placement: Below the first browse surfaces, replacing generic lower copy.
- Sections: What the library is built for, How to browse, Printing notes

## Gallery Landing
- Metadata: Unique main gallery title and description.
- Placement: Below the gallery and collection browsing sections.
- Sections: What you can find, Choosing a page, Printing tips

## Hub Pages
- Metadata: One unique title and description per Phase 1 hub.
- Placement: Below the printable gallery and supporting browse links.
- Required fields: pageTitle, metaTitle, metaDescription, h1, shortIntro, aboveGalleryValueBullets, belowGallerySections, relatedHubLinks, internalLinkStrategy, pinterestDescription, canonicalPath, noIndex, sitemap

The model keeps long-form guidance below the gallery experience and uses generated Phase 1 links only.
